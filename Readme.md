# NLP Assignments

This repository contains coursework for NLP, organized by assignment.

## Contents
- `Assignment1/`: POS tagging plus figurative language detection.
  - Tasks: build a POS tagger; implement a baseline figurative language recognizer; improve the recognizer.
  - Artifacts: notebook and PDF report.
- `Assignment2/`: Sequence modeling with recurrent baselines and residual recurrent models.
  - Tasks: data preparation (preprocessing, sequencing, validation split, PyTorch dataloaders); baseline model implementation/training/validation; residual recurrent models with evaluation.
  - Artifacts: notebook, PDF report, trained model checkpoints (`.pt`), and validation metric plots.
- `Assignment3/`: Transformer work focused on BERT.
  - Tasks: implement BERT components from scratch (multi-head self-attention, feed-forward, encoder layer, full model); tokenize and test; preprocess the Fakeddit dataset; fine-tune BERT.
  - Artifacts: notebook, PDF report, and zip bundle.

## Notes
Each assignment folder contains its own materials, code, and reports.
